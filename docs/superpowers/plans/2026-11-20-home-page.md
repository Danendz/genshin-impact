# Home Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the `/` health check with the legacy home screen (background, option icons, profile card, tile grid, settings), with unfinished pages visibly locked.

**Architecture:** A new `apps/web/src/home/` folder mirrors `src/characters/`: pure helpers (`profile.ts`, `background.ts`) with unit tests, small components, one CSS module ported from legacy SCSS, and route-level tests through `makeRouter` with a mocked `api`. Browser storage goes through one try/catch helper. The saved locale joins `resolveLocale`, so `/characters` follows the choice too.

**Tech Stack:** React 19, TanStack Router + Query, CSS Modules + Tailwind v4, Vitest + Testing Library, Biome.

**Spec:** `docs/superpowers/specs/2026-11-20-home-page-design.md`

- No tile navigates to a blank or 404 page. Only `character-archive` and `character` link to `/characters`, carrying `?locale=` when present.

- World level: AR ≤ 19 → 0, else ⌊(AR − 20) / 5 + 1⌋ (8 at AR 57).
- Background crossfade every 8 s, never the same image twice in a row, next image preloaded; dark fallback while loading/failed.
- Storage: one key for the profile `{ avatarId, uid }`, one for the locale; every access in try/catch; page works with storage throwing.
- `resolveLocale` order: `?locale=` → saved locale → browser languages → `en`.
- Styling goes through tokens: colours as `--color-*` in `apps/web/src/styles/theme.css` (Tailwind utilities like `bg-ink`, `text-gold`), durations `--dur-*`, layers `--z-*`. New legacy colours are added to `theme.css` first; `src/styles/tokens.test.ts` fails on raw colours in CSS modules or TSX.
- Reduced motion: the global rule in `theme.css` already shortens every CSS animation/transition; JS motion goes through `animateOut` (`src/characters/motion.ts`), which checks the same query.
- Layers: Escape and focus go through `src/components/layers.ts` — `useModalLayer(ref, onClose)` for the settings panel and anything modal (the avatar picker gets it via `Modal`), `useEscape(onClose)` for non-modal panels.

## Review Focus

1. **`?locale=` in the URL while picking a language in Settings** — `?locale=` outranks the saved value, so the pick would appear to do nothing; picking must drop `locale` from the search (Task 6 test).
2. **Corrupt or foreign storage values** (`"{"`, `{uid:"x"}`, a 3-digit uid, a non-locale string) — fall back to defaults/regenerate, never crash (Task 2 and Task 1 tests).
3. **Background list with 0 or 1 items** — no timer spin, no crash, single image stays (Task 4 tests).
4. **Clipboard unavailable or rejecting** (`navigator.clipboard` undefined in insecure contexts) — Copy does not throw; no "copied" popup on failure (Task 5 test).
5. **Character list failing** — placeholders render, the avatar button is disabled, tiles still link (Task 7 test).
